Lemonade Engines

Add engines to the Lemonade you already run. Each engine runs as its own server on this computer and joins Lemonade as a provider, so its models show up in Lemonade's list and work in every app that talks to Lemonade. Press Set up on an engine: it installs it, starts it, adds it to Lemonade and asks it one test question, and shows each step as it goes.
